Built for government servers and legacy systems

Light, local, no paid cloud services, and nothing existing has to change.

PROTOTYPE
synthetic data
SPEED

Fast on modest servers

  • Matching only inside one institution
  • Lookups by institution ID; SQLite now, PostgreSQL later
  • Text similarity runs locally (small ONNX model); simple keyword scoring if the model is unavailable
  • Heavy checks run when a complaint arrives, not on every page view
LEGACY

Works with what exists

  • Portals are not modified; they send one JSON call with an API key
  • Each portal keeps its own database and case numbers
  • Bureau systems can post actions to the hub (POST /api/actions)
  • Rules (category owner, SLA, action stance) are tables an administrator can edit
TRUST

Private and accountable

  • Synthetic data only; reporter phone stored only as a hash
  • Role-based views; signed login tokens
  • Every decision and case-file download is in the audit trail
  • No external AI service; humans decide
FUTURE SCOPE

Next steps for a real rollout

  • Aadhaar / DigiLocker verification instead of mock OTP
  • Government single sign-on for officers
  • Email / SMS notifications
  • PostgreSQL and a queue for very high volume
  • Integration with the live AICTE portal
  • Multilingual matching; case graph view
